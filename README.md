<h4 align="center">

<p align="center">Zombie JS is a top-down zombie shooter, made in JavaScript using the <a href="https://p5js.org"> P5.JS library.</a> </p>

<h3>Controls</h3>
<p><img src="https://github.com/Furkan5E/Zombie.JS/blob/master/assets/zombies/zombie.png" width="18.1" height="14.1" </img>  Use WASD to move around</p>
<p><img src="https://github.com/Furkan5E/Zombie.JS/blob/master/assets/zombies/fastZombie.png" width="18.1" height="14.1" </img>  Use mouse to aim and left mouse button click to shoot the zombies</p>
<p><img src="https://github.com/Furkan5E/Zombie.JS/blob/master/assets/zombies/strongZombie.png" width="18.1" height="14.1" </img>  You have 3 lives if the zombies get you, it's game over</p>
<p><img src="https://github.com/Furkan5E/Zombie.JS/blob/master/assets/zombies/splitZombie.png" width="18.1" height="14.1" </img>  However, if you beat all 20 waves you win</p>
<p><img src="https://github.com/Furkan5E/Zombie.JS/blob/master/assets/zombies/bossZombie.png" width="18.1" height="14.1" </img>  Each zombie is unquie in it's own way so watch out</p>
